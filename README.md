# Kerala Flood-Year Prediction

## 1. Project Overview

This project aims to develop a Machine Learning-based classification system to predict flood years in Kerala using historical monthly rainfall data.

The study investigates whether rainfall patterns can help identify years associated with major flooding events and how early a potential warning can be generated.

## 2. Problem Domain

Disaster Management

## 3. Problem Statement

To classify historical years in Kerala as flood or non-flood years based on monthly rainfall patterns using supervised Machine Learning algorithms.

## 4. Dataset

- Dataset: Rainfall in Kerala (1901–2017)
- Source: Kaggle
- Original data source: IMD / data.gov.in
- Features: Monthly rainfall measurements

For dataset source and licensing information,
see [data/README.md](data/README.md).

## 5. Machine Learning Algorithms

The following algorithms will be implemented:

1. Logistic Regression
2. Decision Tree
3. K-Nearest Neighbours
4. Naive Bayes
5. Support Vector Machine

## 6. Evaluation Metrics

- Recall
- F1-score
- ROC-AUC
